# Tablas en Juego

App web infantil para aprender y practicar las tablas de multiplicar del 1 al 10 jugando.

## Características

- Hecha solo con HTML, CSS y JavaScript.
- Funciona directamente abriendo `index.html` en el navegador.
- Tres modos de juego: globos, tren y estrellas rápidas.
- Selector de tabla individual o modo aleatorio con todas las tablas.
- Sonidos de acierto y error generados con JavaScript.
- Fuegos artificiales al alcanzar rachas de 10 aciertos.
- Progreso por tabla y medallas guardadas en el navegador.
- Diseño responsive para PC, tablet y móvil.

## Uso

Abre `index.html` en cualquier navegador moderno.
